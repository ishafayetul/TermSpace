## TermSpace 1.1.0

This update brings the Tokyo Night redesign, live theme switching, and terminal font controls to TermSpace on Ubuntu 24.04 LTS.

- Choose from 15 themes, including Ubuntu light/dark detection. Apply themes to the application, a workspace, a tab, or an individual pane.
- Create, edit, duplicate, and share custom themes. Imports use validated local JSON.
- Zoom with Ctrl+Plus, Ctrl+Equal, Ctrl+Minus, Ctrl+0, the equivalent numeric keypad keys, or Ctrl+mouse wheel. Choose whether zoom applies to the focused pane, the current tab, or every window.
- Save per-pane font sizes with workspaces. Theme changes and zoom keep the existing shell and PTY running.

### Install or upgrade

Download the Debian package and checksum below. Run these commands in the download directory:

```bash
sha256sum -c termspace_1.1.0_all.deb.sha256
sudo apt install ./termspace_1.1.0_all.deb
```

Existing TermSpace configurations and saved workspaces are read by this release. Custom themes are stored locally and can be exported separately for use on another installation.

### Verification

The native suite passed 33 tests on X11 and 32 on headless GNOME Wayland, with the X11-only input test skipped on Wayland. Coverage includes workspace restoration, PTY resizing, theme switching during active terminal programs, and theme import security.
