## TermSpace 1.0.0

The first public release for Ubuntu 24.04 LTS. TermSpace runs independent Linux shells in native GTK/VTE panes and saves reusable terminal layouts locally.

- Split panes recursively, reorder tabs, and move or maximize panes while their sessions continue running.
- Save workspaces, restore layouts, and customize shell profiles, themes, and shortcuts.
- Review potentially unsafe paste content and explicitly approve any saved startup commands before they run.
- Import bounded JSON workspaces with startup commands removed and custom profile selection disabled.

### Install

Download the Debian package and checksum below. In the download directory:

```bash
sha256sum -c termspace_1.0.0_all.deb.sha256
sudo apt update
sudo apt install ./termspace_1.0.0_all.deb
termspace
```

The package uses Ubuntu's VTE security updates and requires the patched GTK4 VTE package. To remove TermSpace, run `sudo apt remove termspace`. Your saved workspaces remain in your home directory.

### Verification and limits

All 25 automated tests passed on X11 and on GNOME Wayland, including 16 simultaneous PTYs and regressions for clipboard handling, workspace consent, and child-process cleanup. Installation and removal with apt passed in a disposable Ubuntu 24.04 container. Workspaces restore layout and configuration by starting fresh shells. Detached jobs may outlive terminal closure. See the [test record](https://github.com/ishafayetul/TermSpace/blob/v1.0.0/docs/TESTING.md) and [security policy](https://github.com/ishafayetul/TermSpace/security/policy) for details.
