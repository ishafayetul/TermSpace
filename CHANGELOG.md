# Changelog

## 1.1.0

- Redesigned the GTK interface around Tokyo Night with clearer tabs, pane headers, focus borders, and workspace status.
- Added 15 theme choices, custom theme editing and validated JSON import/export, and per-workspace, tab, and pane themes.
- Added live font zoom by keyboard and mouse, configurable zoom scopes, and saved per-pane font sizes.
- Added font, cursor, spacing, padding, and opacity controls with live previews.

## 1.0.0

- Added native GTK/VTE windows, independent shells, tabs and recursive split panes.
- Added local profiles, versioned workspace storage, and one-time startup command review.
- Added controlled paste, output search, keyboard bindings, appearance settings and desktop integration.
- Added the Ubuntu Debian package, dependency checker and native test suite.
